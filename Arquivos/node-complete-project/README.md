# Node Complete Project

A complete Node.js project with TypeScript and various dependencies.

## Installation

1. Clone or download the project.
2. Run `npm install` to install dependencies.

## Development

Run `npm run dev` to start the development server with hot reload.

## Build

Run `npm run build` to compile TypeScript to JavaScript.

## Start

Run `npm start` to start the production server.

## Dependencies

This project includes a wide range of dependencies for various functionalities like Express server, database connections (MySQL, Redis), messaging (AMQP), PDF generation, email sending, and more.
